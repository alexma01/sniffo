See and change your network traffic.
For free.

Sniffo is an open-source HTTP/HTTPS debugging proxy for macOS. Every feature is included, nothing is behind a paid tier.

Download for macOS View on GitHub 
brew install --cask alexma01/tap/sniffo

What it does

Capture everything

HTTP/1.1, HTTP/2, HTTPS, WebSocket, GraphQL and gRPC from this Mac, LAN devices, iOS Simulator and Android.

One-click setup

Local root CA and system proxy, restored on exit and after a crash.

Change traffic on the fly

Breakpoints, Map Local, Map Remote, Block, throttling and JavaScript rules. Unlimited.

Inspect and replay

JSON, XML, form and hex viewers, diff, Compose, copy as cURL, HAR import and export.

Phones and emulators

QR code and a certificate page for devices on Wi-Fi, adb reverse for Android.

Native and light

Built with Tauri 2: a Rust proxy core and a React UI.
